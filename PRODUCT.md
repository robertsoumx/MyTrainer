# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
CS2 and VALORANT players practicing aim with mouse, trackpad or touchscreen.
## Product Purpose
Four short, physical aim drills: precision, target switching, tracking, and movement plus shooting. Measure each independently and recommend the weakest measured skill.
## Capabilities and Constraints
GitHub Pages frontend; Three.js rendering and Rapier collisions. Public username and explicit consent on first run, separate input/game leaderboards, local progress, customizable controls and light/dark UI. Existing history is retained but older protocols do not enter new scores. Native game ranks and native game-engine equivalence are not claimed.
## Brand Commitments
Stratum / MyTrainer. User explicitly requests an Aim Lab–inspired range: non-realistic, restrained tech glow, no weapon viewmodel, no decision quizzes, exactly four drills, very little text. Preserve the useful existing UI character while removing clutter. No emojis or marketing slogans.
## Product Principles
- Gameplay is the primary interface.
- A press produces one deterministic shot; the camera never kicks.
- Every score measures the action the drill requests.
- Preserve progress and consent; never fabricate players or game ranks.
