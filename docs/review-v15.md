# Version 1.5: five pre-publication reviews

The frontend was withheld from GitHub Pages while all five passes were completed. Local browser review used the real API implementation and migrations against an isolated local database.

1. **Input and physics.** Audited presses, releases, pointer cancellation, repeated keys, automatic/semi/burst timing and recoil. Added explicit Tap/Hold control, stable camera rendering, ballistic crosshair offset and new acceleration/braking profiles. Kept independent input ownership and weapon-specific timing. Regression checks prove one immediate Tap round while held, correct automatic cadence, and no firing-induced camera pitch.
2. **Original design and rendering.** Restored the earlier graphite/coral panel and card system. Removed the replacement editorial rows, most in-world labels, health/minimap clutter and repeated teaching copy. Added a lightweight 2.5D world path with the licensed viewmodel. Briefs now show the task, duration, weapon and controls before one Start action.
3. **Public data and first use.** Implemented mandatory username/setup and explicit public confirmation, with case-insensitive unique names and hashed device credentials. Implemented real shared D1 storage, timed single-use attempts, ownership checks, server-calculated composites and profile removal. Added empty, loading, invalid input, duplicate-name, unavailable-storage and request-error states. No synthetic players were added.
4. **Desktop and mobile interaction.** Reviewed desktop plus 390 × 844 portrait and 844 × 390 landscape in both themes. Mouse/keyboard and touch taps each spent one round; trackpad clicking spent one round while dragging changed yaw without a second shot. Fixed landscape game selection, reduced remaining settings copy and collapsed secondary settings. Touch controls retain 44 px minimum targets. Physical simultaneous multi-touch and hardware pointer lock remain unverified.
5. **End-to-end timing and comparison.** A full benchmark exposed insufficient exposure accounting under delayed frames. Exposure deadlines now use real active time, tracking samples each rendered observation once, and targets prefer visible positions. Model preparation and pose baking now finish before the benchmark timer and server attempt start; poses are cached across drills. A corrected 30-second precision run recorded ten measured trials and was accepted by the local shared API. The final suite has 94 passing checks, plus passing syntax and graphics builds.

All changes use a new world3d5 mechanical context. Historical measurements remain archived. The world and movement are independent trainer implementations; no native-engine, official-map, game-rank or anti-cheat claim is made.
